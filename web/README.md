# Biswas Digital Hub — Website

Official website for **Biswas Digital Hub**, an internet cafe and digital service centre in Bhabanipur Char, West Bengal.

Built with React 18, TypeScript, Vite, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static site is output to `dist/` and can be hosted on Vercel, Netlify or GitHub Pages.

## Edit content

Services, prices, business details and document checklists live in `src/data.ts`.
